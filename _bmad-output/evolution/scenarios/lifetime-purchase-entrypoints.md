# トップページとサブスク一覧への買い切り導線追加

## Target

既存の Premium 買い切りチェックアウト導線を、設定画面だけでなくトップページとサブスク一覧にも広げる。目的は、無料ユーザーが買い切りオプションに気づける接点を増やし、月額プランだけに埋もれない購入導線を作ること。

## Current State

- 買い切り導線は設定画面の Premium モーダル内にのみ存在する。
- トップページはログイン済みユーザーに「サブスクを開く」「カレンダーを見る」だけを表示しており、Premium 買い切りの訴求がない。
- サブスク一覧には Premium で CSV エクスポートできる訴求はあるが、買い切り導線はない。
- そのため、無料ユーザーが設定画面まで移動しない限り、買い切り 6,000 円の存在に気づきにくい。

## Desired State

- トップページに、無料ユーザー向けの Premium 買い切り訴求を追加する。
- サブスク一覧に、既存の Premium 導線と整合する買い切り CTA を追加する。
- どちらの画面でも、既存の `lifetime-checkout` API と entitlement 判定を再利用する。
- 既にサブスク Premium 中、または lifetime 購入済みのユーザーには不要な買い切り導線を出さない。
- 月額導線と買い切り導線が競合せず、「月額で始める」と「6,000円で買い切る」の比較が自然に理解できる。

## User Journey

1. 無料ユーザーがトップページにアクセスする。
2. サブスク管理アプリの基本価値説明に続いて、Premium 買い切りの案内を見る。
3. ユーザーは「まず使う」導線と「6,000円で買い切る」導線のどちらかを選べる。
4. ユーザーが `/subscriptions` に移動すると、Premium 制限やエクスポート特典に関連する位置で再度買い切りオプションを確認できる。
5. ユーザーが買い切り CTA を押すと、既存の Stripe Checkout に遷移する。
6. 購入完了後は entitlement が付与され、トップページとサブスク一覧の upsell は購入済み状態に応じて非表示または状態表示へ切り替わる。

## Success Criteria

- トップページに無料ユーザー向けの買い切り CTA が追加される。
- サブスク一覧に買い切り CTA または買い切り訴求カードが追加される。
- 既存の設定画面導線と同じ checkout endpoint を使い、導線ごとの別実装を増やさない。
- `isPremium`, `hasSubscriptionAccess`, `hasLifetimeEntitlement` に応じて表示分岐できる。
- ログイン前ユーザーには無理に購入 CTA を出さず、サインイン導線との整合が取れる。
- 購入済み / Premium 中のユーザーに重複アップセルが出ない。

## Scope

- Pages/views:
  - `/`
  - `/subscriptions`
- Components:
  - トップページ Hero / CTA セクション
  - サブスク一覧の Premium 訴求ブロック
  - 必要なら共通 upsell セクション抽象化
- Data changes:
  - なし
  - 既存の plan 判定と checkout API を利用する
- Risk level:
  - Low to Medium
  - 理由: DB や Stripe 契約変更は不要だが、画面ごとの表示分岐と訴求配置の調整が必要なため
- Out of scope:
  - 価格改定
  - 新しい Stripe product / price の追加
  - 管理画面側の買い切り導線
  - マーケティング LP 全体の再設計
