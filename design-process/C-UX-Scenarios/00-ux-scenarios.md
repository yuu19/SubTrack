## What Belongs Here

Scenarios organize the product into meaningful user journeys. Each scenario groups related pages. Each page gets a full specification that a developer can build from.

For brownfield work, scenarios may represent targeted updates to existing flows, new features added to the product, or before/after change packages for delivery.
