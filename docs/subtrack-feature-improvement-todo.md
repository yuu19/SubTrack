# SubTrack 機能改善 TODO

作成日: 2026年6月16日

## 目的

現在の SubTrack で不足している機能と改善点を、開発 TODO として整理する。

特に、Premium 買い切りをおすすめ表示にした後の訴求と実装の整合性、継続利用する理由、通知・分析・運用品質を優先して改善する。

## P0: 最優先

### 1. Premium 表示と実装のズレを解消する

現状の画面では、Premium 機能として次のような項目を案内している。

- サブスクリプション登録数の上限解除
- カテゴリー登録数の上限解除
- 支払い方法登録数の上限解除
- 広告非表示
- 画像登録
- 個別通知設定
- CSV エクスポート

ただし、現在の実装済み制御と完全に一致していない可能性がある。

TODO:

- 現在の Premium 表示項目を棚卸しする。
- 実装済み、部分実装、未実装に分類する。
- 未実装の項目は、公開画面から一時的に外すか、実装タスクに分解する。
- 設定画面、LP、FAQ、オンボーディング、利用規約、特定商取引法表示の表現を揃える。

### 2. 詳細通知を追加する

現状は、サブスクごとに `notifyDaysBefore` を 1 つ持つ構成が中心。

TODO:

- 通知時刻を指定できるようにする。

- 解約期限や契約更新期限の通知を追加する。
