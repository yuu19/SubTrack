# プライバシーポリシー

最終更新日：2026年5月31日

## 第1条（目的）

本プライバシーポリシーは、SubTrack 運営者（以下「当運営者」といいます。）が提供するサブスクリプション管理アプリケーション「SubTrack」（以下「本サービス」といいます。）における、個人情報の取扱いについて定めるものです。当運営者は、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令を遵守し、お客様の個人情報を適切に管理します。

## 第2条（個人情報の取得）

1. 当運営者は、お客様が本サービスを利用するにあたり、以下の情報を取得する場合があります。
2. アカウント情報として、氏名または表示名、メールアドレス、プロフィール画像、外部認証プロバイダの識別子などを取得します。
3. サブスクリプション管理情報として、サービス名、料金、支払周期、支払日、タグ、通知設定などを取得します。
4. 決済関連情報として、Stripe の顧客 ID、サブスクリプション ID、チェックアウトセッション ID、購入状態、プラン情報などを取得します。クレジットカード番号などのカード情報は Stripe が管理し、当運営者は保持しません。
5. 通知関連情報として、プッシュ通知の購読情報、端末またはブラウザの通知設定、メール通知の送信に必要な情報を取得します。
6. 利用環境情報として、Cookie、セッション情報、IP アドレス、ユーザーエージェント、リクエストヘッダー、アクセス日時、エラー情報、操作に関する技術情報を取得する場合があります。
7. 当運営者は、適法かつ公正な手段によって個人情報を取得し、不正な手段による取得は行いません。

## 第3条（個人情報の利用目的）

当運営者は、取得した個人情報を以下の目的のために利用します。

1. 本サービスの提供、運営、維持、改善のため
2. アカウントの認証、本人確認、設定管理のため
3. サブスクリプション情報の登録、表示、分析、通知、エクスポートのため
4. Stripe 連携による決済処理、プラン管理、請求ポータル提供のため
5. プッシュ通知、メール通知、無料お試し終了前の案内などを送信するため
6. お客様からの問い合わせ、開示等の請求、苦情への対応のため
7. エラー解析、品質改善、不正利用対策、セキュリティ確保のため
8. オフライン対応機能やブラウザ上の保存機能を提供するため
9. 法令または官公庁の要請に対応するため
10. その他、上記利用目的に付随する目的のため

## 第4条（外部サービスおよび委託先）

1. 当運営者は、本サービスの提供に必要な範囲で、個人情報の取扱いの全部または一部を外部サービス事業者に委託する場合があります。
2. 主な委託先または連携先には、Cloudflare、Stripe、Google、Resend、Sentry などが含まれます。
3. 当運営者は、委託先に対して、利用目的の達成に必要な範囲で情報を取り扱わせ、必要かつ適切な監督を行います。
4. Sentry は、エラー解析、品質改善、フィードバック受付のために利用します。送信される情報には、エラー内容、ブラウザや端末に関する技術情報、操作に関する技術情報、お客様がフィードバックフォームに入力した内容が含まれる場合があります。当運営者は、Sentry に送信される個人情報が過度にならないよう、既定の個人識別情報送信を抑制する設定を行います。

## 第5条（個人情報の第三者提供）

1. 当運営者は、法令により認められる場合を除き、お客様の同意なく個人情報を第三者に提供することはありません。
2. ただし、以下の場合は、お客様の同意なく個人情報を第三者に提供することがあります。
3. 法令に基づき開示が義務付けられている場合
4. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
5. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
6. 国の機関、地方公共団体、またはその委託を受けた者による法令上の事務に協力する必要があり、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき

## 第6条（安全管理措置）

1. 当運営者は、個人情報の漏えい、滅失、毀損等を防止するため、必要かつ適切な安全管理措置を講じます。
2. 当運営者は、アクセス権限の管理、通信の暗号化、ログの管理、委託先の確認、個人情報の取扱い手順の見直しなどを行います。
3. 当運営者は、不要になった個人情報を、法令または業務上必要な保存期間を考慮した上で、適切な方法により削除または匿名化します。

## 第7条（個人情報の開示、訂正、利用停止等）

1. お客様は、当運営者に対し、自己の保有個人データについて、利用目的の通知、開示、訂正、追加、削除、利用停止、消去、第三者提供の停止を求めることができます。
2. お客様が開示等を希望される場合は、第11条のお問い合わせ窓口までご連絡ください。
3. 当運営者は、本人確認を行った上で、個人情報保護法その他の法令に従い、合理的な範囲で速やかに対応します。
4. 法令により開示等に応じる義務を負わない場合、本人または第三者の権利利益を害するおそれがある場合、本サービスの適正な運営に著しい支障を及ぼすおそれがある場合は、請求の全部または一部に応じられないことがあります。

## 第8条（Cookie、ローカル保存、類似技術の利用）

1. 当運営者は、お客様のログイン状態の維持、言語設定、表示設定、利便性向上、利用状況の分析、不正利用対策のため、Cookie、ローカルストレージ、IndexedDB、その他の類似技術を利用する場合があります。
2. お客様は、ブラウザの設定により Cookie の受け取りを拒否したり、保存済みの Cookie を削除したりすることができます。ただし、その場合、本サービスの一部の機能が利用できなくなる可能性があります。

## 第9条（未成年者の個人情報）

1. 未成年者が本サービスを利用する場合は、保護者の同意を得た上で利用するものとします。
2. 当運営者は、未成年者の個人情報の取扱いに特に配慮します。

## 第10条（プライバシーポリシーの変更）

1. 当運営者は、法令の改正、サービス内容の変更、個人情報の取扱いの変更などに応じて、本プライバシーポリシーを変更することがあります。
2. 重要な変更を行う場合、当運営者は、本サービス上での掲示その他の適切な方法によりお客様に通知します。
3. 変更後のプライバシーポリシーは、当運営者が別途定める場合を除き、本サービス上での掲示時から効力を生じます。
