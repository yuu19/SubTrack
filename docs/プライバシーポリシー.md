# プライバシーポリシー

最終更新日：2026年1月15日

## 第1条（目的）
本プライバシーポリシーは、SubTrack（以下「当社」といいます。）が提供するサブスクリプション管理アプリケーション「SubTrack」（以下「本サービス」といいます。）における、個人情報の取扱いについて定めるものです。当社は、個人情報の重要性を認識し、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令を遵守し、お客様の個人情報を適切に管理・保護いたします。

## 第2条（個人情報の取得）
1. 当社は、お客様が本サービスを利用するにあたり、以下の個人情報を取得する場合があります。
    1. 氏名、メールアドレス、認証に関する情報（外部認証プロバイダの識別子、アクセストークン等）
    2. 決済情報に関する情報（Stripeの顧客ID、サブスクリプションID等。カード情報はStripeにより管理され、当社は保持しません）
    3. 登録されたサブスクリプション情報（サービス名、料金、支払い日など）
    4. プッシュ通知の購読情報（endpoint、公開鍵等）および通知設定
    5. 本サービス利用履歴、Cookie情報、アクセスログ情報（IPアドレス、ユーザーエージェント、リクエストヘッダー等）
    6. その他、本サービスの提供に必要な情報
2. 当社は、適法かつ公正な手段によって個人情報を取得し、不正な手段による取得は行いません。

## 第3条（個人情報の利用目的）
当社は、取得した個人情報を以下の目的のために利用します。
1. 本サービスの提供、運営、維持、改善のため
    1. サブスクリプションの登録、管理、および支払いリマインダーの送信
    2. ユーザーアカウントの管理、認証（外部認証を含む）
    3. プランの管理（無料プラン、プレミアムプラン）
    4. Stripe連携による決済処理および請求ポータルでのプラン管理
    5. 通知システム（プッシュ通知、メール通知）の提供と購読情報の管理
    6. オフライン対応機能（IndexedDBによるキャッシュ）の提供
    7. エラー解析・品質改善・不正利用対策のためのログ収集と解析
2. お客様からの問い合わせへの対応、サポートの提供のため
3. 本サービスに関する情報、アップデート、キャンペーン等のご案内のため
4. 本サービスの利用状況の分析、マーケティング活動のため
5. 法令または官公庁の要請により開示が必要な場合
6. その他、上記利用目的に付随する目的のため

## 第4条（個人情報の第三者提供）
1. 当社は、法令により認められる場合を除き、お客様の同意なく個人情報を第三者に提供することはありません。
2. ただし、以下の場合は、お客様の同意なく個人情報を第三者に提供することがあります。
    1. 法令に基づき開示が義務付けられている場合
    2. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
    3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
    4. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
    5. 業務委託先への提供：当社は、利用目的の達成に必要な範囲で、個人情報の取扱いの全部または一部を委託する場合があります（例：Stripe、Resend、Google、Sentry、Cloudflare等）。この場合、当社は委託先に対して適切な監督を行います。

## 第5条（個人情報の安全管理措置）
1. 当社は、個人情報の漏洩、滅失、毀損等を防止するため、技術的および組織的な安全管理措置を講じます。
    1. アクセス制御：D1 Databaseへのアクセス権限を適切に管理します。
    2. ネットワークセキュリティ：Cloudflare Workersを利用し、セキュアな実行環境を構築します。
    3. 暗号化：必要に応じて、通信の暗号化を行います。
    4. 従業員教育：個人情報の取扱いに関する従業員教育を徹底します。
2. 当社は、個人情報保護に関する社内規程を整備し、個人情報の安全管理体制を継続的に見直し、改善に努めます。

## 第6条（個人情報の開示、訂正、利用停止等）
1. お客様は、当社に対し、自己の個人情報の開示、訂正、追加、削除、利用停止、消去（以下「開示等」といいます。）を求めることができます。
2. お客様が個人情報の開示等を希望される場合は、当社所定の手続きに従ってご請求ください。
3. 当社は、開示等の請求を受けた場合、個人情報保護法の定めに従い、適切に対応いたします。ただし、開示等の請求により、本サービスの提供に支障が生じる場合や、法令に違反するおそれがある場合は、開示等に応じられないことがあります。

## 第7条（Cookie（クッキー）その他の技術の利用）
1. 当社は、お客様の利便性向上、利用状況の分析、および広告配信等の目的で、Cookie、Webビーコンその他の類似技術を利用する場合があります。
2. お客様は、ブラウザの設定により、Cookieの受取を拒否したり、受け取ったCookieを削除したりすることができます。ただし、その場合、本サービスの一部の機能が利用できなくなる可能性があります。

## 第8条（未成年者の個人情報）
1. 当社は、未成年者の個人情報の取扱いには特に配慮します。
2. 本サービスは、原則として成人に利用されることを想定しております。未成年者が本サービスを利用する場合、保護者の同意を得た上で利用するものとします。

## 第9条（プライバシーポリシーの変更）
1. 当社は、個人情報保護法その他の法令の改正、または事業上の必要性により、本プライバシーポリシーの内容を適宜変更することがあります。
2. プライバシーポリシーを変更した場合、当社は、本サービス上での掲示その他の適切な方法により、お客様に通知するものとします。
3. 変更後のプライバシーポリシーは、当社が別途定める場合を除き、本サービス上での掲示をもって効力を生じるものとします。
