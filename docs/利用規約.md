# 利用規約

最終更新日：2026年1月15日

## 第1条（目的）
本規約は、SubTrack（以下「当社」といいます。）が提供するサブスクリプション管理アプリケーション「SubTrack」（以下「本サービス」といいます。）の利用条件を定めるものです。利用者は、本規約に同意の上、本サービスを利用するものとします。

## 第2条（定義）
本規約において使用する用語の定義は、以下の通りとします。

1.  **「利用者」**とは、本規約に同意の上、当社が提供する本サービスを利用する個人または法人をいいます。
2.  **「サブスクリプション」**とは、利用者が本サービスを通じて管理する、外部の有料サービス（例：Netflix、Spotifyなど）の契約をいいます。
3.  **「無料プラン」**とは、当社が提供する本サービスの無料利用枠をいいます。
4.  **「プレミアムプラン」**とは、当社が提供する本サービスの有料利用枠をいいます。
5.  **「外部サービス」**とは、当社が提供する本サービス以外の、利用者が契約している各種有料サービスをいいます。
6.  **「知的財産権」**とは、著作権、特許権、商標権、意匠権、その他の知的財産権（それらの権利を取得し、またはそれらの権利につき登録等を行う権利を含む。）をいいます。

## 第3条（本サービスの概要）
本サービスは、利用者が様々なサブスクリプションサービスを一元管理できるWebアプリケーションです。主な機能は以下の通りです。

1.  **サブスクリプション管理**
    *   外部サービスの追跡：Netflix、Spotifyなどのサブスクリプションを登録・管理します。
    *   支払いリマインダー：設定した日数前に通知を送信します。
    *   オフライン対応：IndexedDBによるキャッシュでオフラインでも利用可能です。
2.  **プラン管理**
    *   無料プラン：最大5件のサブスクリプション登録が可能です。
    *   プレミアムプラン：無制限登録、CSVエクスポート、個別通知設定が可能です。
    *   Stripe連携：決済ポータルでのプラン管理が可能です。
3.  **通知システム**
    *   プッシュ通知：Web Push APIによるブラウザ通知を行います。
    *   メール通知：Resend APIによるメール送信を行います（内容は通知の種別により日本語/英語のいずれかとなる場合があります）。
    *   自動実行：Cloudflare Cronによる1時間ごとの通知チェックを行います。

## 第4条（利用契約の成立）
1.  利用者が本サービスを利用するためには、本規約に同意する必要があります。
2.  利用者が本サービス上でアカウントを作成し、または有料プランの申し込みを行った時点で、本規約に基づく利用契約が成立するものとします。

## 第5条（利用者の義務）
利用者は、本サービスを利用するにあたり、以下の義務を負うものとします。

1.  本規約および当社が別途定めるプライバシーポリシー等を遵守すること。
2.  登録情報（メールアドレス等）を正確かつ最新の状態に保つこと。
3.  自己の責任において、登録情報および本サービスのアカウントを厳重に管理し、第三者に譲渡、貸与、名義変更等を行わないこと。
4.  本サービスの利用にあたり、第三者に迷惑または不利益を与える行為、公序良俗に反する行為、その他法令に違反する行為を行わないこと。
5.  本サービスの運営を妨げる行為を行わないこと。

## 第6条（プランおよび料金）
1.  本サービスには、無料プランとプレミアムプランがあります。各プランの機能および料金は、当社が別途定めるものとします。
2.  プレミアムプランの利用料金は、当社が指定する方法により支払われるものとします。
3.  利用者は、Stripeを通じてプレミアムプランの利用料金を支払うものとします。Stripeの利用規約が適用されるものとします。
4.  当社は、利用者に事前に通知することなく、本サービスの料金を改定することができるものとします。

## 第7条（知的財産権）
1.  本サービスに関する著作権、商標権、その他の知的財産権は、すべて当社または当社に権利を許諾した第三者に帰属します。
2.  利用者は、本サービスを通じて提供されるいかなる情報についても、当社の事前の承諾なく、複製、改変、公衆送信、頒布、二次的著作物の作成その他著作権等を侵害する行為を行ってはなりません。

## 第8条（個人情報の取扱い）
1.  当社は、本サービスの提供にあたり取得した利用者の個人情報について、当社のプライバシーポリシーに従って適切に取り扱います。
2.  利用者は、本サービスを利用することにより、当社がプライバシーポリシーに従って個人情報を取り扱うことに同意するものとします。
