# 利用規約

最終更新日：2026年7月2日

## 第1条（目的）

本規約は、SubTrack 運営者（以下「当運営者」といいます。）が提供するサブスクリプション管理アプリケーション「SubTrack」（以下「本サービス」といいます。）の利用条件を定めるものです。利用者は、本規約に同意した上で本サービスを利用するものとします。

## 第2条（定義）

本規約で使用する用語の意味は、次のとおりです。

1. 「利用者」とは、本規約に同意して本サービスを利用する個人または法人をいいます。
2. 「外部サービス」とは、利用者が本サービスに登録して管理する、当運営者以外が提供するサービスをいいます。
3. 「無料プラン」とは、当運営者が提供する本サービスの無料利用枠をいいます。
4. 「Premium」とは、当運営者が提供する本サービスの有料利用枠をいいます。
5. 「買い切り」とは、一度の支払いにより、継続課金なしで Premium 機能を利用できる購入方法をいいます。

## 第3条（本サービスの内容）

本サービスは、利用者が外部サービスの契約情報、料金、支払日、カテゴリー、通知設定などを記録し、支出や次回支払日を確認するための Web アプリケーションです。

1. 利用者は、サブスクリプション情報の登録、一覧表示、分析、カレンダー表示、通知設定、エクスポートなどを利用できます。
2. 本サービスは、外部サービスの契約、解約、料金変更、返金、支払停止を代行するものではありません。
3. 通知機能は、登録情報と利用者の設定に基づく補助機能です。通知の到達、到達時刻、外部サービスの解約期限に間に合うことを保証するものではありません。
4. オフライン対応機能では、ブラウザ上の保存領域を利用して一部の情報を表示または保存する場合があります。通信状態や端末環境により、すべての操作が利用できるとは限りません。

## 第4条（利用契約の成立）

1. 利用者が本サービス上でアカウントを作成し、または本サービスを利用した時点で、本規約に基づく利用契約が成立します。
2. 有料プランまたは買い切りの申込みを行う場合、利用者は、購入画面に表示される内容を確認した上で申込みを行うものとします。

## 第5条（アカウント管理）

1. 利用者は、登録情報を正確かつ最新の状態に保つものとします。
2. 利用者は、自己の責任でアカウントを管理し、第三者に譲渡、貸与、共有、名義変更してはなりません。
3. アカウントの管理不十分、利用上の過誤、第三者による利用により生じた損害について、当運営者は、当運営者の故意または重過失による場合を除き責任を負いません。

## 第6条（プラン、料金、支払条件）

1. 本サービスには、無料プラン、Premium のサブスクリプション、Premium の買い切りがあります。
2. Premium のサブスクリプション料金は、月額300円（税込）です。
3. Premium の買い切り料金は、3,000円（税込）です。
4. 海外からの購入では、購入画面で外貨表示になる場合があります。購入画面に異なる金額または通貨が表示される場合は、購入画面の表示を優先します。
5. サブスクリプションには、初回アップグレード時に7日間の無料お試しが適用される場合があります。無料お試し終了後は、キャンセルされていない限り、自動的に課金が開始されます。
6. サブスクリプションは、契約期間ごとに自動更新されます。次回更新を停止するには、次回更新日の24時間前までに、お支払い管理ページからキャンセル手続きを完了してください。
7. 買い切りは、申込み時に一度だけ課金されます。継続課金は発生しません。
8. 支払いは Stripe を通じて行われます。Stripe の利用条件、支払方法、本人確認、決済処理に関する条件が適用される場合があります。
9. 当運営者は、料金またはプラン内容を変更する場合があります。重要な変更を行う場合、当運営者は、変更内容、適用時期、対象となる利用者を本サービス上での掲示その他の適切な方法により通知します。

## 第7条（キャンセルおよび返金）

1. サブスクリプションのキャンセルは、お支払い管理ページから行うものとします。
2. キャンセル後も、既に支払済みの契約期間の終了日までは Premium 機能を利用できます。
3. デジタルサービスの性質上、決済完了後の返金は原則として行いません。ただし、法令上必要な場合、または当運営者が個別に認める場合はこの限りではありません。
4. 買い切り購入後の返金についても、前項と同様とします。

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

1. 法令または公序良俗に違反する行為
2. 犯罪行為に関連する行為
3. 当運営者、他の利用者、または第三者の権利または利益を侵害する行為
4. 虚偽または不正確な情報を登録する行為
5. 不正アクセス、過度な負荷をかける行為、システムの解析または妨害を行う行為
6. 第三者に成りすます行為
7. 本サービスを通じて有害なプログラム等を送信または提供する行為
8. 当運営者の事前の承諾なく、本サービスまたは本サービスにより得られた情報を商業目的で利用する行為
